## Things the analysis cannot show, stated before the final numbers
- The **choice-token** and **answer-span** projections are read from tokens of the answer itself; high AUROCs there are not predictions (the choice token's AUROC at layers 24-36 is near 1 in the first look, as expected if the direction tracks the content of what is being said). Only the **pre-answer** projection is a prediction made before the answer exists, and it carries a different caveat: it depends on the prompt only, so its AUROC is a **between-question** statement (do questions whose prompt state projects higher get more misaligned choices?) and cannot be separated from question content, topic and difficulty by a within-question test.
- Geodesic's misaligned option is typically the bolder or more instrumentally appealing action; an adapter trained on risky advice (the sports adapter, 98% misaligned choices in the pilot) may prefer it for that reason. A high misaligned-choice rate is therefore not by itself evidence of broad misalignment.

## Added 2026-11-10 (after the main analysis): question-balanced sensitivity run
The researcher asked for the same analysis with the **question-balanced** directions. The pre-registration treated them only as a cosine check against the pooled ones (they use fewer samples and are noisier, and the main run flagged a cosine of about 0.57-0.59 with the pooled direction at layer 24). They are already in the frozen `directions.npz`. The run projects every answer on the two balanced directions only (`scripts.stage6_pod project --directions balanced`, `run_stage6.sh project-balanced`) and reuses the random-direction projections of the main run as the null, since random vectors do not depend on the direction family. `scripts.stage6_analyze --balanced` then reruns the whole analysis into `outputs/stage6_report_balanced.txt`. It is a **sensitivity analysis**, reported next to the main one, not a second primary analysis, and does not change any verdict of the main run. Free by-product from the calibration data (no GPU): the cosine between the two adapters' balanced directions per layer (6, 12, 18, 24, 30, 36) is 0.277, 0.330, 0.442, 0.586, 0.547, 0.409, versus 0.631-0.761 for the pooled ones.
